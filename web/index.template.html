Methodology

  • Data: the public Banking77 dataset (PolyAI), test split, CC BY 4.0. Full citation in the repository's ATTRIBUTION.md.
  • n = — messages, the full test split — no sampling.
  • Accuracy (fine): share of messages routed to the exact correct one of 77 intents. Accuracy (coarse): share routed to the correct one of 10 broader groups.
  • Cost per 1,000 messages: mean input/output tokens per message, priced from the dated sheet below.
  • p50 / p95 latency: the typical and slow-case response time, in seconds.
  • Brier score: how well a model's stated confidence matches its real accuracy — lower is better, 0 is perfect.
  • Prices as of —. Results generated —.
  • Known limits: one shared prompt for every model (not tuned per model), a single AWS region, and a single day's run — model behavior can vary run to run.
